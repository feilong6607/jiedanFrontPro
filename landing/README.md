# 接单护盾 · 落地页骨架

偏后端程序员「平台外私活」防坑工具包的落地页（承接层）。
当前为**骨架版本**：6 个区块结构已就位，文案 / 截图 / 真实链接为占位，后续填充。

## 技术栈
- Vue 3 + Vite
- 纯前端单页，部署到 Vercel（或任意静态托管）

## 本地运行
```bash
npm install
npm run dev      # 本地开发预览 http://localhost:5173
npm run build    # 产出 dist/ 静态文件
npm run preview  # 预览构建产物
```

## 部署（Vercel）
1. 推送到 GitHub 仓库
2. 在 Vercel 导入该仓库，`framework` 已设为 vite，自动识别
3. 或本地：`npx vercel`
