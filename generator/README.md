# 接单护盾 · 私活防坑文档生成器（MVP）

偏后端程序员「平台外私活」的接单文档生成器。表单填一次 → 自动套模板 → 导出 PDF / Markdown。

## 技术栈
- Vue 3 + Vite + marked（Markdown 渲染）
- 纯前端，零后端，可部署到 Vercel / GitHub Pages / 任意静态托管

## 包含的模板
| 模板 | 版本 | 说明 |
|------|------|------|
| 私活软件开发服务合同 | 免费 | 分期付款 / 变更书面确认 / 尾款前不交源码 / 逾期视为验收 / 异议须指具体条款+证据 |
| 接单确认单（轻量版） | 免费 | 一页纸快速对齐 + 留证 |
| 软件开发项目报价单 | 高级 | 多行工作项明细表 + 费用合计 |
| 项目需求确认单 | 高级 | 必做/选做拆分 + 验收标准，锁范围 |
| 项目验收单 | 高级 | 不通过须勾选具体条款+证据 + 尾款释放 |

## 本地运行
```bash
npm install
npm run dev        # 开发预览 http://localhost:5173
npm run build      # 产出 dist/
npm run preview    # 预览构建产物
```

## 部署（Vercel）
仓库根目录即本项目，`vercel.json` 已配置 vite 框架 + SPA 回退，直接 Import 即可。
