# 接单护盾（freelance-shield）

> 偏后端程序员的「平台外私活」防坑工具包 —— 把接单的行政杂事标准化、留痕化，不再被白嫖、被拖尾款、说不清。

## 这是什么
一套开源的**接单文档模板 + 接单确认单**，覆盖私活从「接单 → 报价 → 需求确认 → 交付 → 验收 → 回款」全链路的书面留痕。模板由「接单护盾」工具生成，本仓库为模板源与示例。

## 适用人群
- 想接平台外私活、怕被坑 / 白嫖 / 拖尾款的偏后端程序员。
- 不想养重运营、希望用标准化文档保护自己的人。

## 模板清单（`templates/`）
| 文件 | 用途 | 法律属性 |
|------|------|----------|
| `contract.md` | 私活软件开发服务合同（中性、双方对等） | 正式合同参考 |
| `quote.md` | 项目报价单 | 报价凭证 |
| `requirement.md` | 需求确认单 | 范围锁定 |
| `acceptance.md` | 项目验收单 | 回款触发 |
| `deal-confirm.md` | 接单确认单（轻量版） | 非正式备忘 |
| `_DISCLAIMER.md` | 通用免责声明（每份模板必含） | —— |

## ⚠️ 重要免责
本仓库所有模板**仅供参考，不构成法律意见**。涉及金额大、周期长、关系复杂的项目，请先咨询执业律师。详见 `templates/_DISCLAIMER.md`。

## 使用方式
1. 复制对应模板，替换 `{{占位符}}`。
2. 双方填写、签字（或电子确认）后各自留存。
3. 升级到「一键生成」网页工具（规划中）可自动套用并导出。
